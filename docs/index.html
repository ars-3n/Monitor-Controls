Monitor Controls for Mac

Brightness and volume for your external monitors, in the menu bar

macOS can't set the brightness or the speaker volume of most external monitors. Monitor Controls can. It talks to the display over DDC/CI, the control link that runs through the display cable, and keeps sound and the microphone on the devices you rank highest.

Free and open source · macOS 14 or later · Apple silicon

Everything for the desk in one panel

The menu-bar icon is a small monitor with two sliders, and its knobs sit at the current brightness and volume. Click it for the panel.

The brightness keys work on your monitor

Turn on Brightness and volume keys in Settings and the keys on your Mac's keyboard control external monitors too. Brightness keys change the display under the pointer, and a small indicator under the menu-bar icon shows the new level. Volume and mute follow the active output.

Sound goes where you want it

Put your outputs and microphones in order in Settings. When a device higher in the list connects, Monitor Controls switches to it, and when it disconnects, the next one takes over. A device you pick yourself stays in use until it disconnects or a higher one connects.

The eye button hides a device you never want, such as the virtual one a meeting app installs. Audio Priority Bar users can import their saved order once.

A slider for each monitor

Every external monitor gets its own brightness slider, and the display changes while you drag.

Volume for any output

Monitor speakers are set over DDC/CI. Any other output, such as AirPods, uses the macOS volume.

Microphone gain and mute

The microphone row sets input gain and mute when the device supports them. A muted device's button turns red.

Alerts follow the output

macOS can leave sound effects on the MacBook speakers after you switch to a monitor. Monitor Controls moves them to the output in use.

Mute the Mac's own speakers

While another output is in use, point at the speakers' row in the panel and a mute button appears for anything that still plays there.

Updates when you ask

Check for Updates in Settings looks for a newer release only when you press it, and Install and Relaunch swaps it in.

Install

  1. Download MonitorControls.zip and unzip it.
  2. Move Monitor Controls.app to Applications and open it.
  3. Click the monitor icon in the menu bar. Right-click it for Settings and Quit.

Releases aren't notarized, so the first time you open the app macOS says it can't verify it. Close the message, go to System Settings → Privacy & Security, and click Open Anyway next to the line about Monitor Controls. The keys also need access under Privacy & Security → Accessibility.

Questions

Why can't my Mac change the brightness of my external monitor?

macOS sets the brightness only of Apple's own displays and a few made for the Mac, such as the LG UltraFine. Other monitors take brightness and volume commands over DDC/CI, and macOS doesn't send them. Monitor Controls does.

Which monitors work?

Monitors with DDC/CI, which most desktop monitors have. Some ship with it switched off in their own menu, and some docks and adapters don't pass it through. The panel says which controls are unavailable.

Does it run on Intel Macs?

No. Releases are built for Apple silicon (M1 and later) and need macOS 14 or later.

How is it different from MonitorControl?

The display code is adapted from MonitorControl. Monitor Controls puts it in one panel with the output volume, microphone gain and automatic switching between your audio devices, which MonitorControl doesn't do. If you run both, turn off MonitorControl's key handling so one app handles each keypress.

Is it free?

Yes. Monitor Controls is open source under the GPL-3.0, and every release is on GitHub.
